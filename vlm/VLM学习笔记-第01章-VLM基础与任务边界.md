# 第 1 章：VLM 基础与任务边界

> 本章目标不是背模型名称，而是建立一张地图：什么是视觉语言模型，它能处理哪些任务，它和图像生成模型、VLA 有什么区别，以及一张图片究竟怎样参与语言模型的回答。

## 2. 什么是模态

“模态”（Modality）可以理解为信息的表现形式。

| 模态 | 原始形式 | 模型常见表示 |
|---|---|---|
| 文本 | 字、词、句子 | 文本 Token 和向量 |
| 图像 | 二维像素网格 | Patch Token 或视觉特征 |
| 视频 | 连续图像帧，可能带声音 | 帧 Token、时序特征 |
| 音频 | 随时间变化的波形 | 声学帧或音频 Token |
| 动作 | 关节、位置、按钮、轨迹 | 离散动作 Token 或连续向量 |

单模态模型只处理一种主要信息。例如纯文本 LLM 输入和输出都是文本 Token。多模态模型需要让不同形式的信息在模型内部发生关联。

### 2.1 多模态不只是“输入种类多”

真正困难的地方不是把图片和文字同时传给程序，而是让模型学会：

- 图片中的哪些区域对应文字中的哪些概念；
- 同一个词在不同图片中指向哪个对象；
- 图片里没有直接写出的关系怎样用语言表达；
- 多张图片或多个视频帧之间怎样建立时间和空间关系；
- 视觉证据不足时应该承认无法判断，而不是凭语言习惯猜测。

## 3. VLM 是什么

VLM 是 Vision-Language Model，即视觉语言模型。广义上，只要一个模型联合处理视觉和语言，都可以称为 VLM。

这个定义覆盖范围很大：

```text
图像 + 文本 → 相似度              CLIP 类图文检索模型
图像 + 问题 → 类别/短答案          传统 VQA 模型
图像 + 指令 → 自由文本             LLaVA、Qwen-VL 等生成式 VLM
视频 + 问题 → 答案/时间位置        视频 VLM
屏幕截图 + 指令 → 点击/输入操作     GUI Agent 模型
```

因此，“VLM”不是某一种固定网络结构，也不必然等于一个可以聊天的大模型。

### 3.1 现代语境中的 VLM

现在人们谈到通用 VLM 时，通常指：

```text
视觉编码器 + 跨模态连接/融合模块 + 大语言模型
```

它既具有视觉感知能力，又继承 LLM 的语言理解、指令跟随和文本生成能力。例如 LLaVA 使用视觉编码器、跨模态连接器和 LLM 组成视觉对话模型；其核心贡献之一是使用视觉指令数据进行训练。

### 3.2 VLM 的最小工作流程

```text
用户图片                      用户文字
   │                            │
   ▼                            ▼
图像预处理                    Tokenizer
   │                            │
   ▼                            ▼
视觉编码器                    文本 Token
   │                            │
   ▼                            │
视觉特征                       │
   │                            │
   ▼                            │
连接器 / 融合模块 ──────────────┘
              │
              ▼
       多模态上下文表示
              │
              ▼
             LLM
              │
              ▼
          逐 Token 生成答案
```

这张图只是通用抽象。不同模型可能使用 Projector、Q-Former、Resampler 或 Cross-Attention，也可能从基础预训练阶段就更深地融合视觉和语言。

## 4. 什么是 MLLM

MLLM 通常是 Multimodal Large Language Model，即多模态大语言模型。

它强调模型以大型语言模型为核心，并增加图片、视频、音频等输入能力。生成式 VLM 往往也是 MLLM，但二者并非严格同义：

| 术语 | 强调重点 | 覆盖范围 |
|---|---|---|
| VLM | 视觉与语言的联合建模 | 包括 CLIP、传统 VQA、生成式 VLM |
| MLLM | 以 LLM 为核心的多模态理解和生成 | 可能同时支持视觉、音频等多种模态 |
| LMM | Large Multimodal Model | 与 MLLM 常被混用，定义依论文而异 |
| 多模态基础模型 | 可迁移到多种模态任务的大规模基础模型 | 范围更宽，可包含生成、理解、行动 |

实践中不要过度纠结名称，应先看它的输入、输出、训练目标和架构。

## 5. 图片怎样进入语言模型

### 5.1 LLM 不能直接读取像素

纯文本 LLM 接收的是一串整数 Token ID。图片则是形如 `H × W × C` 的像素数组，二者结构完全不同。

例如一张 `224 × 224` RGB 图片包含：

```text
224 × 224 × 3 = 150,528 个像素通道值
```

如果把每个像素都当作一个 Token，序列太长，而且单个像素缺少稳定语义。因此通常先把图片切成 Patch，再由视觉编码器提取特征。

### 5.2 从图片到视觉 Token

假设图片大小为 `224 × 224`，Patch Size 为 `14 × 14`：

```text
横向 Patch 数 = 224 / 14 = 16
纵向 Patch 数 = 224 / 14 = 16
视觉 Patch 数 = 16 × 16 = 256
```

每个 Patch 经线性映射后变成一个向量，可以把它看作视觉 Token。视觉编码器继续用 Transformer 等网络让各 Patch 交换信息。

### 5.3 为什么还需要连接器

即使视觉编码器输出 1,024 维向量，LLM 可能使用 4,096 维隐藏状态，而且两个模型训练出的向量空间含义不同。

```text
视觉编码器空间                       LLM 语言空间
“像猫的局部视觉纹理”  ──连接器──▶  “可作为上下文理解的猫概念”
```

连接器不只是机械改变维度，还需要通过图文数据训练，让视觉特征落到 LLM 能利用的表示空间中。第 6 章会详细比较各种连接器。

## 6. Tokenizer 与视觉处理器不是一回事

文本通常经过 Tokenizer：

```text
“图片里有什么？” → [图片, 里, 有, 什么, ？] → Token ID
```

图片通常经过 Image Processor：

```text
图片 → 缩放/裁剪/归一化 → 像素张量 → 视觉编码器
```

有些模型还会使用特殊文本 Token 标记图片位置：

```text
<image> 请描述这张图片。
```

`<image>` 本身通常不包含整张图像的信息，它更像一个占位符。真正的视觉特征会在模型内部插入或融合到对应位置。

| 组件 | 处理对象 | 是否通常需要训练 |
|---|---|---|
| 文本 Tokenizer | 字符串 | 通常先独立训练词表，VLM 阶段一般固定 |
| Image Processor | 原始图片 | 缩放和归一化规则通常不是神经网络训练出来的 |
| Vision Encoder | 像素张量 | 需要预训练或联合训练 |
| Projector/连接器 | 视觉特征 | 通常需要图文数据训练 |
| LLM | 多模态上下文 | 可冻结、LoRA 或全参数训练 |

## 7. VLM 的主要任务

## 7.1 Image Caption：图片描述

输入一张图片，输出自然语言描述。

```text
输入：公园里一只狗追着飞盘的图片
输出：一只棕色小狗正在草地上追逐红色飞盘。
```

Caption 不只是物体分类，还涉及对象、属性、动作和关系。评价时会遇到“一张图片存在多种正确描述”的问题。

## 7.2 图文检索

有两种方向：

- Text-to-Image：给一句文字找相关图片；
- Image-to-Text：给图片找相关描述。

CLIP/SigLIP 类模型通常输出相似度，而不是长文本答案。

## 7.3 VQA：视觉问答

VQA 是 Visual Question Answering。

```text
图片 + “桌上有几个杯子？” → “三个”
```

VQA 可以分为：

- 闭集分类：答案来自固定候选集合；
- 多项选择：从若干答案中选择；
- 开放生成：自由生成文本；
- 知识型 VQA：需要视觉证据和外部知识；
- 推理型 VQA：需要多步数学、空间或因果推理。

## 7.4 OCR 与文档理解

OCR 是 Optical Character Recognition，即光学字符识别。但现代文档 VLM 的目标通常超过“把字抄出来”：

```text
识别文字
  ↓
恢复版面结构
  ↓
理解标题、段落、表格和字段关系
  ↓
根据文档回答问题或提取结构化信息
```

常见任务包括票据字段提取、合同问答、表格理解、图表推理和复杂页面解析。

## 7.5 Grounding：语言与视觉位置对应

Grounding 要求模型不仅知道“有什么”，还要知道“在哪里”。

```text
输入：图片 + “请找出穿红衣服的人”
输出：边界框 [x1, y1, x2, y2]，或一个点/掩码
```

相关概念：

| 任务 | 输入 | 输出 |
|---|---|---|
| Object Detection | 图片 | 类别和多个框 |
| Referring Expression Comprehension | 图片和语言描述 | 描述对应的框 |
| Grounded Caption | 图片 | 带区域位置的描述 |
| Segmentation Grounding | 图片和描述 | 像素级掩码 |

坐标可以用数值、离散位置 Token 或特殊格式生成。输出格式正确不代表定位正确，通常还要计算 IoU。

## 7.6 多图理解

多图任务不是简单把图片分别描述一遍，还包括：

- 找两张图的不同；
- 比较商品或图表；
- 根据连续截图理解操作过程；
- 在多页文档中跨页查找证据；
- 理解图片之间的因果或时间关系。

模型必须保存每张图的身份和顺序，避免把对象混在一起。

## 7.7 视频理解

视频可以看作大量带时间顺序的图片帧，但直接处理所有帧通常成本过高。

```text
视频 → 抽帧/切片 → 帧级视觉编码 → 时间位置表示 → LLM
```

典型任务：

- 视频描述和问答；
- 动作识别；
- 事件时间定位；
- 长视频摘要；
- 根据多个时刻进行因果推理。

视频任务的关键难点包括抽帧遗漏、动作顺序、长上下文和字幕泄漏。

## 7.8 GUI Agent

GUI Agent 需要理解电脑或手机界面，并采取操作：

```text
屏幕截图 + 用户目标
  ↓
识别按钮、输入框和界面状态
  ↓
规划下一步
  ↓
输出 click(x,y)、type(text)、scroll 等动作
  ↓
获得新截图并继续
```

它比普通 VQA 多了环境交互、状态变化和多步决策。一次截图回答正确，不代表能连续完成任务。

## 7.9 多模态 RAG

多模态 RAG 会从图片、PDF、图表、视频或文本库中检索证据，再交给模型回答。

```text
问题 → 多模态检索 → 找到文本/图片证据 → VLM 生成答案
```

需要分别评价检索是否找对、模型是否忠于证据，以及最终答案是否正确。

## 8. VLM 与 CLIP 类模型的区别

| 维度 | CLIP/SigLIP 类 | 生成式 VLM/MLLM |
|---|---|---|
| 典型输出 | 图文相似度或 Embedding | 自由文本、坐标、工具调用 |
| 主要目标 | 图文表征对齐 | 根据视觉和文字生成下一个 Token |
| 文本模型 | 通常是文本编码器 | 通常是生成式 LLM |
| 适合任务 | 检索、分类、Embedding | 对话、VQA、OCR、推理、Agent |
| 是否能长回答 | 通常不能 | 可以 |
| 是否需要连接器 | 双塔本身通常不需要接 LLM | 通常需要连接或深度融合机制 |

CLIP 本身也是 VLM，但通常不是人们所说的“视觉聊天大模型”。

---

## 9. VLM 与图像生成模型的区别

### 9.1 理解型 VLM

```text
图片 + 文本指令 → 文本答案
```

它的主要输出空间是文本 Token，核心目标是理解视觉内容并用语言回答。

### 9.2 图像生成模型

```text
文本/参考图 → 新图片或视频
```

扩散模型通常学习逐步去噪，输出的是像素或潜空间表示，不是普通语言答案。

### 9.3 为什么边界正在变模糊

有些统一多模态模型既能理解图片，也能生成视觉内容。但判断能力时仍应分别看：

- 输入模态；
- 输出模态；
- 输出 Token/表示类型；
- 训练损失；
- 是否包含独立图像解码器或扩散模块。

不能因为模型支持“图片输入”，就推断它能生成图片。

---

## 10. VLM 与 VLA 的区别

VLA 是 Vision-Language-Action Model，即视觉—语言—动作模型。

```text
VLM：图片 + 指令 → “机器人应该拿起红色杯子”
VLA：图片 + 指令 → 机械臂关节或末端执行器动作序列
```

| 维度 | VLM | VLA |
|---|---|---|
| 主要输出 | 文本、坐标、工具调用 | 机器人或环境动作 |
| 数据 | 图文对话、VQA、视频等 | 视觉、语言与动作轨迹 |
| 评价 | 答案正确、定位、幻觉 | 任务成功率、安全、轨迹效率 |
| 风险 | 语言错误或视觉幻觉 | 可能直接造成物理世界后果 |

VLM 可以作为 VLA 的视觉理解或规划基础，但把文字计划转换成稳定的连续控制仍需要动作建模、控制频率、机器人状态和安全约束。

---

## 11. VLM 与传统计算机视觉模型的区别

传统专用视觉模型往往为固定任务训练：

```text
分类器：图片 → 固定类别
检测器：图片 → 类别 + 框
分割器：图片 → 像素掩码
```

通用 VLM 则通过语言统一任务接口：

```text
图片 + “图中是什么？”            → 描述
图片 + “红色汽车在哪里？”        → 坐标
图片 + “比较两个柱子的数值”      → 推理答案
```

通用性不等于所有专用任务都更强。专用模型通常输出更稳定、速度更快、格式更可控；VLM 的优势是任务迁移、开放词汇和语言交互。

## 12. VLM 是怎样训练出来的：先建立全局认识

详细训练将在第 10～13 章展开，本章先看通用路线。

```text
阶段 A：训练视觉编码器
图片 → 学会视觉特征

阶段 B：图文对齐/连接器训练
图片—文字对 → 让视觉特征进入语言空间

阶段 C：多模态预训练
大规模图文、交错文档、视频 → 学习多任务能力

阶段 D：视觉指令微调
图片 + 指令 + 答案 → 学会按人类指令回答

阶段 E：偏好优化或强化学习
多个回答 + 偏好/规则奖励 → 提高推理、格式、安全和帮助性
```

不是所有模型都严格采用这五步。有的冻结视觉编码器和 LLM，只训练连接器；有的会逐步解冻；原生多模态模型可能从基础预训练阶段就混合文本、图片和视频。

### 12.1 生成式 VLM 常见损失

在视觉指令训练中，最常见的核心损失仍是下一个 Token 预测：

```text
图片 + “这是什么动物？” + “这是一只熊猫。”
                         ↓
模型依次预测：这 → 是 → 一 → 只 → 熊 → 猫
```

通常只对答案部分计算语言建模损失，而把系统提示、用户问题和视觉占位位置遮蔽掉。视觉证据通过上下文影响答案 Token 的概率。

这说明 VLM 不一定需要一个名为“视觉损失”的单独目标，语言生成损失也能训练视觉连接器；但早期视觉预训练或图文对齐阶段可能使用对比、匹配、蒸馏等其他损失。

## 13. 为什么 VLM 会产生视觉幻觉

视觉幻觉是模型描述了图片中不存在、看不清或无法确定的内容。

### 13.1 常见原因

1. 语言先验过强：模型学到“餐桌通常有盘子”，于是没看清也回答有盘子；
2. 视觉分辨率不足：小字或小物体被缩放丢失；
3. 视觉 Token 压缩过多：细节在连接器中消失；
4. 数据描述不准确：训练 Caption 本身包含错误；
5. 问题带诱导：用户问“红车旁边的人在做什么”，但图片里没有红车；
6. 解码追求流畅：语言模型更愿意生成自然完整的故事；
7. 多图或视频混淆：把另一张图或另一时间点的信息挪过来。

### 13.2 如何检查模型是否真正看图

可以设计对照实验：

```text
原图 + 问题 → 答案 A
移除图片 + 同一问题 → 答案 B
替换图片 + 同一问题 → 答案 C
遮挡关键区域 + 同一问题 → 答案 D
```

如果答案几乎不变，模型可能主要依赖语言先验。第 14 章会把这种测试纳入正式评估体系。

## 14. VLM 的能力层次

```text
第 1 层：感知
识别对象、颜色、文字、数量
          ↓
第 2 层：定位与关系
对象在哪里、谁在谁旁边、先后顺序
          ↓
第 3 层：语义理解
场景含义、图表趋势、文档字段关系
          ↓
第 4 层：多步推理
数学、科学、空间、因果推理
          ↓
第 5 层：交互与行动
工具调用、GUI 操作、环境反馈和规划
```

高层能力依赖低层视觉证据，但 Benchmark 高分并不自动证明每一层都可靠。模型可能通过数据记忆、OCR 文本或语言捷径得到正确答案。

## 15. 一个统一的任务分析模板

以后遇到任何“视觉多模态模型”，先填写下面这张表：

| 问题 | 需要确认的内容 |
|---|---|
| 输入是什么 | 单图、多图、视频、文本、音频、状态？ |
| 输出是什么 | 相似度、文本、坐标、掩码、图片还是动作？ |
| 视觉怎样编码 | CNN、ViT、CLIP、SigLIP、DINO？ |
| 怎样连接语言模型 | Projector、Q-Former、Cross-Attention、原生融合？ |
| 怎样训练 | 对比学习、生成损失、SFT、偏好优化、RL？ |
| 哪些模块可训练 | 视觉编码器、连接器、LLM、动作头？ |
| 数据是什么 | 图文对、交错文档、对话、视频、轨迹？ |
| 怎样评估 | 准确率、生成质量、IoU、幻觉、任务成功率？ |
| 资源代价 | 图片分辨率、视觉 Token、显存、延迟？ |

用这套模板，就不容易被“多模态”“原生”“统一”等宣传词带偏。

## 16. 常见误区

### 误区 1：所有 VLM 都是能聊天的大模型

不对。CLIP 也是视觉语言模型，但主要输出图文相似度。

### 误区 2：视觉 Token 就是图片里的文字 Token

不对。视觉 Token 通常来自图像 Patch 的向量表示；OCR 识别到的文字还可以进一步转成文本 Token。

### 误区 3：有 LLM 就一定具备视觉能力

不对。纯文本 LLM 没有接收和训练视觉表示的机制。

### 误区 4：接上视觉编码器就完成了图文对齐

不对。视觉特征和 LLM 隐藏空间需要通过连接器和图文数据训练建立对应关系。

### 误区 5：图片分辨率越高一定越好

不一定。更高分辨率可能保留小字和细节，但会增加视觉 Token、显存和延迟，还受训练分布限制。

### 误区 6：回答正确就说明模型看懂了图片

不一定。它可能利用问题中的语言线索、数据记忆或常识猜中答案。

### 误区 7：能输出坐标就一定定位准确

不对。格式正确只是第一步，还要用 IoU、点命中率等指标检查位置。

### 误区 8：VLM 能生成文字，所以也能生成图片

不对。是否能生成视觉内容取决于输出表示和是否存在相应解码器或生成目标。

### 误区 9：VLM 可以直接变成机器人控制器

不对。VLA 还需要动作数据、状态建模、连续控制和安全约束。

### 误区 10：模型名称中的参数量就是视觉部分参数量

通常不是。模型标称参数可能包含 LLM、视觉编码器、连接器和 MoE 专家；还要区分总参数与激活参数。

## 17. 本章总结

```text
VLM 的本质：联合建模视觉和语言

图片先经过视觉编码器变成视觉特征，
再经连接或融合机制进入语言模型。

VLM 范围很广：
CLIP 输出相似度；生成式 VLM 输出文字；
Grounding 输出位置；GUI Agent 输出工具动作。

图像生成模型的主要输出是视觉内容；
VLA 的主要输出是环境或机器人动作。

判断模型类型时，不看宣传名称，
而看输入、输出、编码器、融合方式、训练目标和评估方法。
```
